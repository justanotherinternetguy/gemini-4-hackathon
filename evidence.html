How the crew works

The router does the bulk. Gemini agents finish the board, one checked step at a time.

Classic router

Freerouting

Routes about 97% of each board, then leaves a few connections open.

Lead

gemini-4-carbon

Looks at a picture of the board and writes one strategy note for the crew.

Four step agents

gemini-4-hydrogen

Careful, bold, layer-first and power-aware, each on its own copy of the board.

KiCad acts

router + rule check

Every step is one action: route, route with a via, rip up, roll back. KiCad does the copper.

Judge

PCBWorld evaluate_one

Scores every saved board. The best board is the one submitted.

Each step:observe fresh facts→decide one action→KiCad routes→rule check judges→keep the best or roll backup to 20 steps per agent

Control arm

A random policy with the same actions and the same step budget. No model.

Blocker screen

gemini-decision-1

Names the routed nets that wall off an open connection (whole-plan arm).

Managed Agent specialist

gemini-4-hydrogen, long-running

One agent per stuck board, with coarse tools on the same engine, for boards nothing else fixes.
